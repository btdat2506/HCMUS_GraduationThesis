## Hardware Blocks Generated by Gemmini defaultConfig

### 1. **Systolic Array (Mesh)**
- **16x16 Processing Elements (PEs)** - The main computational core
- **Tiling**: 1x1 tiles (single tile configuration)
- **Dataflow**: BOTH (supports both Weight Stationary and Output Stationary)
- **Data Types**: 8-bit signed integer input, 32-bit signed integer accumulator, 20-bit intermediate output

### 2. **Memory Subsystem**

#### **Scratchpad Memory**
- **Capacity**: 256KB for input/weight data
- **Banks**: 4 banks for parallel access
- **Configuration**: Single-ported (sp_singleported = true)

#### **Accumulator Memory**  
- **Capacity**: 64KB for output accumulation
- **Banks**: 2 banks
- **Configuration**: Dual-ported (acc_singleported = false)

### 3. **Control Units**

#### **Reservation Station**
- **Load entries**: 8 entries for memory load operations
- **Store entries**: 4 entries for memory store operations  
- **Execute entries**: 16 entries for computation operations

#### **Controllers**
- **LoadController**: Handles data movement from external memory to scratchpad
- **StoreController**: Handles data movement from scratchpad/accumulator to external memory
- **ExecuteController**: Controls systolic array operations and data flow

### 4. **DMA Engine**
- **StreamReader**: For reading data from external memory
- **StreamWriter**: For writing data to external memory
- **Max in-flight requests**: 16 concurrent memory transactions
- **DMA bus width**: 128 bits
- **Max bytes per transfer**: 64 bytes

### 5. **Specialized Units**

#### **Im2Col Unit**
- Hardware accelerator for image-to-column transformations
- Essential for efficient convolution operations

#### **TLB (Translation Lookaside Buffer)**
- **Size**: 4 entries
- **Purpose**: Virtual-to-physical address translation
- **Ports**: 2 TLB client ports

#### **Scaling Units**
- **Input scaling** (mvin_scale): 8-bit integer to float conversion with saturation
- **Accumulator scaling** (acc_scale): 32-bit accumulator to 8-bit output with saturation
- Both use IEEE 754 single-precision floating-point arithmetic

### 6. **Neural Network Support Features**
- **Training convolutions**: Enabled (has_training_convs = true)
- **Max pooling**: Enabled (has_max_pool = true) 
- **Non-linear activations**: Enabled (has_nonlinear_activations = true)

### 7. **Loop Unrollers**
- **LoopConv**: Handles convolution loop transformations
- **LoopMatmul**: Handles matrix multiplication loop optimizations

### 8. **Performance Monitoring**
- **CounterController**: 8 performance counters for monitoring system behavior
- Various event counters throughout the design

### 9. **Clock Gating**
- **ClockGate**: Power management through clock gating when idle

### 10. **Queue Structures**
- **Instruction queues**: 8 entries for loads, 2 for stores, 8 for execution
- **Command queues**: Buffer incoming instructions
- **Response queues**: Handle completion notifications
